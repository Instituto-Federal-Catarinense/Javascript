# JavaScript Educacional

## Visão geral

Este repositório organiza o aprendizado de **JavaScript** — tanto para **frontend** quanto para **backend** — em **seis módulos** estruturados de forma progressiva.

1️⃣ **Módulo 01 – Fundamentos** – tipos, operadores, controle de fluxo, funções, arrays e objetos.
2️⃣ **Módulo 02 – DOM e Interatividade** – manipulação do DOM, eventos, formulários, validação e Web Storage.
3️⃣ **Módulo 03 – Programação Assíncrona** – callbacks, promises, async/await, fetch API e tratamento de erros.
4️⃣ **Módulo 04 – Node.js Básico** – ambiente de execução, módulos, npm, filesystem e introdução ao Express.
5️⃣ **Módulo 05 – Projeto Full‑Stack** – arquitetura MVC, API REST, conexão front‑end/back‑end, deploy.
6️⃣ **Módulo 06 – Avançado** – performance, testing (Jest), segurança, design patterns e boas práticas.

Cada módulo contém:
- Um **README** com objetivo de aprendizagem, pré‑requisitos e lista de tópicos.
- Código de exemplo **.js** ou **.html** em subpastas temáticas.
- Exercícios e *challenge* com *hints*.
- Um **arquivo de avaliação** (`quiz.md`) para auto‑avaliação.

> **Como usar**
> 1. Siga a ordem dos módulos.
> 2. Leia o README do módulo, execute os exemplos e resolva os exercícios.
> 3. Complete o quiz ao final de cada módulo para validar a compreensão.
