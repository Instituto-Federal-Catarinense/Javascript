# REST API

## Objetivo
Construir rotas CRUD com HTTP, status codes e `Router`.

## Conceitos Teóricos
GET consulta, POST cria, PUT atualiza e DELETE remove. Status 2xx indica sucesso, 4xx erro do cliente e 5xx erro do servidor.

## Exemplos de Código
Execute `npm install` e `npm start`; use `/usuarios` com JSON.

## Exercícios Práticos
1. Adicione paginação.
2. Valide campos obrigatórios.
3. Separe controller e serviço.
