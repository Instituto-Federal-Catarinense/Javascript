# npm e package.json

## Objetivo
Gerenciar projetos, dependências e scripts com npm.

## Conceitos Teóricos
`package.json` descreve o projeto. Dependências de produção ficam em `dependencies`, ferramentas em `devDependencies`; scripts rodam com `npm run` e pacotes podem ser testados com `npx`.

## Exemplos de Código
O `package.json` contém um script mínimo para iniciar o projeto.

## Exercícios Práticos
1. Inicialize um pacote com `npm init`.
2. Instale uma dependência e observe o lockfile.
3. Crie um script personalizado.
