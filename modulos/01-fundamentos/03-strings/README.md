# Strings

## Objetivo
Manipular textos, pesquisar trechos, substituir conteúdo e montar mensagens.

## Conceitos Teóricos
Strings são imutáveis. Métodos como `slice`, `trim`, `replace`, `split`, `includes`, `startsWith`, `endsWith`, `toUpperCase` e `indexOf` devolvem novos valores.

## Exemplos de Código
`strings.js` apresenta mais de quinze operações comuns em uma frase.

## Exercícios Práticos
1. Normalize um nome removendo espaços e capitalizando-o.
2. Conte palavras usando `split`.
3. Substitua termos proibidos por `***`.
