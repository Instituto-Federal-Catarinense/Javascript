# Condicionais

## Objetivo
Escolher caminhos com `if`, `switch`, ternário e guard clauses.

## Conceitos Teóricos
Condicionais avaliam expressões verdadeiras ou falsas. Guard clauses encerram cedo uma função e reduzem aninhamento.

## Exemplos de Código
`condicionais.js` classifica notas e demonstra `switch` e retorno antecipado.

## Exercícios Práticos
1. Classifique uma nota em conceitos.
2. Faça um menu com `switch`.
3. Valide dados obrigatórios com guard clauses.
