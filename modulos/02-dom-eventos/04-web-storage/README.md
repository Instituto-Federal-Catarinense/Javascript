# Web Storage

## Objetivo
Persistir preferências e pequenos dados no navegador.

## Conceitos Teóricos
`localStorage` persiste entre sessões e `sessionStorage` dura enquanto a aba existir. Ambos armazenam strings; use JSON para arrays e objetos e trate chaves com cuidado.

## Exemplos de Código
Abra `index.html` para adicionar, ler e remover itens persistidos.

## Exercícios Práticos
1. Salve o tema escolhido.
2. Implemente CRUD de tarefas com JSON.
3. Limpe dados de uma chave com confirmação.
