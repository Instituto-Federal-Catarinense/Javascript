# Tratamento de Erros

## Objetivo
Detectar, lançar e tratar falhas previsíveis.

## Conceitos Teóricos
`try/catch/finally` separa o fluxo normal do tratamento. Lance `Error` com mensagens úteis e diferencie tipos específicos quando necessário.

## Exemplos de Código
`erros.js` valida entrada, trata `SyntaxError` de JSON e garante limpeza em `finally`.

## Exercícios Práticos
1. Crie um erro de saldo insuficiente.
2. Trate um JSON inválido.
3. Use uma classe de erro customizada.
