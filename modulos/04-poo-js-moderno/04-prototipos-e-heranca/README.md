# Protótipos e Herança

## Objetivo
Entender a cadeia de protótipos e compartilhar comportamento entre objetos.

## Conceitos Teóricos
Objetos delegam propriedades ao seu protótipo. `Object.create` define essa delegação explicitamente; classes são uma sintaxe sobre o mesmo modelo.

## Exemplos de Código
`prototipos.js` cria objetos com `Object.create` e inspeciona a cadeia.

## Exercícios Práticos
1. Crie um protótipo de veículo.
2. Adicione um método compartilhado.
3. Compare `hasOwnProperty` com o operador `in`.
