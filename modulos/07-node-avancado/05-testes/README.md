# Testes

## Objetivo
Escrever testes unitários com Jest.

## Conceitos Teóricos
`describe` agrupa cenários, `test` descreve comportamento e `expect` faz asserções. Testes unitários isolam uma função.

## Exemplos de Código
Execute `npm install` e `npm test`.

## Exercícios Práticos
1. Teste entradas negativas.
2. Adicione testes de exceção.
3. Gere cobertura de código.
