# Debugging

## Objetivo
Investigar erros com logs, breakpoint e o inspector do Node.js.

## Conceitos Teóricos
`console` registra contexto; `debugger` pausa a execução quando o inspector está conectado. Use `node --inspect` e observe pilha, variáveis e fluxo.

## Exemplos de Código
Execute `node debugging.js` e depois `node inspect debugging.js` para explorar o breakpoint.

## Exercícios Práticos
1. Encontre o erro de uma função.
2. Adicione logs estruturados.
3. Inspecione uma Promise pendente.
