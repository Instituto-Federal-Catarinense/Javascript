# WebSockets

## Objetivo
Trocar mensagens em tempo real com Socket.io.

## Conceitos Teóricos
WebSockets mantêm uma conexão persistente. Socket.io oferece eventos, salas e fallback de transporte.

## Exemplos de Código
Execute `npm install`, `npm start` e abra a página em duas abas.

## Exercícios Práticos
1. Mostre usuários conectados.
2. Crie salas de conversa.
3. Persista o histórico.
