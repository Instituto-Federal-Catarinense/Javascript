# Módulo 03 – Programação Assíncrona

Este módulo foca em técnicas de programação assíncrona em JavaScript.

## Tópicos
- Callbacks
- Promises
- async/await
- fetch API e tratamento de erros
- APIs públicas (ex.: JSONPlaceholder)

## Como usar
1. Execute os exemplos em `exemplos/` usando Node ou navegador.
2. Resolva os exercícios em `exercicios/`.
3. Complete o quiz em `quiz.md`.
