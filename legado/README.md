# Legado — material histórico

Este diretório preserva o material produzido na disciplina **Desenvolvimento Web II**
antes da reestruturação do repositório. Ele é mantido **apenas como referência
histórica**: não recebe correções, não segue o padrão atual de código e **não faz
parte da trilha de estudo**.

| Projeto | O que era | Substituído por |
|---|---|---|
| `express-generator/` | App gerado pelo `express-generator` com views em Jade | `modulos/06-express-rest/` |
| `expressjs/` | Exemplo mínimo de Express com arquivos estáticos | `modulos/06-express-rest/02-middleware-express/` |
| `saudacao-mvc/` | Mini-app MVC em Express com formulário | `modulos/06-express-rest/04-rest-api/` |

## Por que manter?

1. Comparar abordagens antigas (Jade/Pug, callbacks) com as atuais.
2. Preservar o histórico de commits e a autoria original.
3. Servir de material para discussão em aula sobre evolução de ferramentas.

**Não utilize este código como modelo.** Prefira sempre os módulos numerados em `modulos/`.
