# Funções

## Objetivo
Declarar funções reutilizáveis e trabalhar com parâmetros, callbacks e IIFEs.

## Conceitos Teóricos
Funções podem ser declarações, expressões ou arrows. Parâmetros padrão, rest e callbacks ajudam a criar APIs flexíveis.

## Exemplos de Código
`funcoes.js` mostra cada formato e uma função que recebe outra função.

## Exercícios Práticos
1. Crie uma calculadora com callback de operação.
2. Some uma quantidade variável de argumentos.
3. Encapsule uma configuração em uma IIFE.
