# Objetos

## Objetivo
Modelar dados com objetos e acessar suas propriedades com sintaxe moderna.

## Conceitos Teóricos
Objetos agrupam propriedades e métodos. Destructuring extrai dados, spread copia propriedades e `Object.keys`, `values` e `entries` permitem percorrê-los. Optional chaining evita erros em caminhos ausentes.

## Exemplos de Código
`objetos.js` combina criação, alteração, cópia, rest e optional chaining.

## Exercícios Práticos
1. Modele um aluno com notas e método de média.
2. Crie uma cópia alterando apenas uma propriedade.
3. Liste as entradas de um objeto em uma tabela textual.
