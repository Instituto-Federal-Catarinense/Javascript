# Tipos de Dados

## Objetivo
Reconhecer os tipos primitivos, usar `typeof` e compreender coerção de tipos e template literals.

## Conceitos Teóricos
JavaScript possui `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol`, `null` e `object`. Valores podem ser convertidos implicitamente ou explicitamente; prefira conversões claras quando a intenção importar.

## Exemplos de Código
Veja `tipos.js`. Execute com `node tipos.js` e observe também as particularidades de `typeof null` e `NaN`.

## Exercícios Práticos
1. Classifique valores usando uma função baseada em `typeof`.
2. Converta texto de formulário para número e trate entradas inválidas.
3. Monte uma mensagem com template literal.
