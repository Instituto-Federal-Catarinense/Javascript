# Operadores

## Objetivo
Combinar valores com operadores aritméticos, lógicos, relacionais e de decisão.

## Conceitos Teóricos
Use `===` e `!==` para comparações sem coerção. `&&`, `||` e `??` trabalham com curto-circuito; o operador ternário expressa uma escolha simples.

## Exemplos de Código
`operadores.js` reúne aritmética, precedência, comparação, ternário e nullish coalescing.

## Exercícios Práticos
1. Calcule o preço final com desconto.
2. Valide idade e autorização usando operadores lógicos.
3. Reescreva um `if` curto usando ternário e `??`.
