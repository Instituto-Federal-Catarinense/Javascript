# Classes e POO

## Objetivo
Criar classes, herdar comportamento e encapsular regras com getters e setters.

## Conceitos Teóricos
`constructor` inicializa instâncias; `extends` e `super` formam hierarquias. Métodos `static` pertencem à classe, enquanto getters e setters controlam propriedades.

## Exemplos de Código
`poo.js` implementa pessoas e estudantes.

## Exercícios Práticos
1. Modele uma conta bancária.
2. Crie uma subclasse de veículo.
3. Valide uma propriedade com setter.
