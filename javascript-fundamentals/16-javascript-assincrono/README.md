# JavaScript Assíncrono

## Objetivo
Coordenar callbacks, Promises e funções `async`/`await`.

## Conceitos Teóricos
Promises representam operações futuras. `Promise.all` espera todas; `Promise.race` resolve com a primeira. `async` sempre retorna Promise e `await` torna o fluxo mais legível.

## Exemplos de Código
`async.js` executa tarefas simuladas com sucesso, erro, `all` e `race`.

## Exercícios Práticos
1. Converta um callback em Promise.
2. Busque três recursos com `Promise.all`.
3. Adicione timeout usando `Promise.race`.
