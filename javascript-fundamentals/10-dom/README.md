# DOM

## Objetivo
Ler e alterar a árvore de elementos de uma página.

## Conceitos Teóricos
O DOM representa o HTML como objetos. Selecione nós com `getElementById` e `querySelector`, crie elementos, anexe-os e manipule classes com `classList`.

## Exemplos de Código
Abra `index.html` e observe a lista criada por `dom.js`.

## Exercícios Práticos
1. Crie uma lista de tarefas dinamicamente.
2. Alterne uma classe ao clicar em um botão.
3. Remova um elemento selecionado.
