# Closures e Escopo

## Objetivo
Compreender escopo léxico e preservar estado privado em closures.

## Conceitos Teóricos
Uma closure mantém acesso às variáveis do escopo onde foi criada, mesmo depois que a função externa terminou. Isso permite fábricas, contadores e encapsulamento.

## Exemplos de Código
`closures.js` cria um contador cujo estado não fica exposto diretamente.

## Exercícios Práticos
1. Crie uma fábrica de multiplicadores.
2. Encapsule configurações de uma aplicação.
3. Implemente memoização simples.
