# Fetch API

## Objetivo
Consumir APIs HTTP com GET, POST, PUT, DELETE e cabeçalhos.

## Conceitos Teóricos
`fetch` retorna uma Promise. Verifique `resposta.ok`, leia JSON com `response.json()` e envie corpo serializado com `Content-Type: application/json`.

## Exemplos de Código
Abra `index.html`; o exemplo usa JSONPlaceholder e demonstra GET e POST.

## Exercícios Práticos
1. Liste recursos de uma API pública.
2. Envie um cadastro com POST.
3. Implemente editar e excluir usando PUT e DELETE.
