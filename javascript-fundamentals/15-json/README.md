# JSON

## Objetivo
Serializar dados e interpretar respostas no formato JSON.

## Conceitos Teóricos
JSON representa dados com objetos, arrays, strings, números, booleanos e `null`. `JSON.stringify` converte para texto e `JSON.parse` reconstrói o valor.

## Exemplos de Código
`json.js` mostra serialização, reviver e uso de dados como uma resposta de API.

## Exercícios Práticos
1. Salve um cadastro como JSON.
2. Ignore uma propriedade ao serializar.
3. Trate uma resposta que não seja JSON válido.
