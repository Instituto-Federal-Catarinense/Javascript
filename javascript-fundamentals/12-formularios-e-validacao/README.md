# Formulários e Validação

## Objetivo
Capturar dados e fornecer feedback de validação nativa e customizada.

## Conceitos Teóricos
Inputs fornecem valores por `.value`. A validação nativa usa `required`, `type` e `minLength`; `setCustomValidity` adiciona regras próprias.

## Exemplos de Código
Abra `index.html` e teste os estados de erro e sucesso.

## Exercícios Práticos
1. Valide confirmação de senha.
2. Mostre mensagens por campo.
3. Desabilite o envio enquanto houver erro.
