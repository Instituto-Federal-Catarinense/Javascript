# Arrays

## Objetivo
Transformar, filtrar, localizar, ordenar e reduzir coleções.

## Conceitos Teóricos
Arrays têm métodos mutáveis como `push` e `pop`, e métodos funcionais como `map`, `filter`, `reduce`, `find`, `some`, `every`, `sort` e `flat`. `sort` altera o array original.

## Exemplos de Código
`arrays.js` usa uma lista de produtos para mostrar mais de quinze operações.

## Exercícios Práticos
1. Calcule a média de uma turma.
2. Filtre produtos abaixo de um preço.
3. Remova duplicados e ordene números sem mutar a lista original.
