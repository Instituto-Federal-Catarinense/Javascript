# Expressões Regulares

## Objetivo
Encontrar e transformar padrões em textos.

## Conceitos Teóricos
`RegExp` usa padrões e flags como `g`, `i` e `m`. `test`, `match` e `replace` resolvem validação, extração e transformação.

## Exemplos de Código
`regex.js` valida email, extrai números e substitui palavras.

## Exercícios Práticos
1. Valide telefone brasileiro.
2. Extraia hashtags de um texto.
3. Mascare parte de um CPF.
