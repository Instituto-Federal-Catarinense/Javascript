# Módulo 02 – DOM e Interatividade

Este módulo aborda a manipulação do Document Object Model (DOM) e a criação de interfaces interativas.

## Tópicos
- Seleção de elementos
- Manipulação de atributos e estilos
- Eventos e delegação
- Formulários e validação
- Web Storage (localStorage, sessionStorage)

## Como usar
1. Abra os exemplos HTML na pasta `exemplos/` em um navegador.
2. Siga os exercícios descritos em `exercicios/`.
3. Complete o quiz em `quiz.md`.
