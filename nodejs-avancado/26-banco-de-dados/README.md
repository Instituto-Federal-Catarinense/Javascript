# Banco de Dados

## Objetivo
Modelar documentos MongoDB com Mongoose e executar CRUD.

## Conceitos Teóricos
Schemas definem formato e validações; Models oferecem operações. A aplicação deve tratar conexão e falhas sem expor credenciais.

## Exemplos de Código
Configure `MONGODB_URI`, execute `npm install` e `npm start` com MongoDB disponível.

## Exercícios Práticos
1. Adicione validação de email.
2. Crie busca por nome.
3. Separe rotas do acesso a dados.
