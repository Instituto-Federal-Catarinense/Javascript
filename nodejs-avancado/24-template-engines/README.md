# Template Engines

## Objetivo
Renderizar páginas HTML dinâmicas com EJS.

## Conceitos Teóricos
EJS usa `<%= valor %>` para escapar conteúdo, tags de código para loops e dados enviados pelo servidor para montar páginas.

## Exemplos de Código
Execute `npm install` e `npm start`; visite `/` e `/sobre`.

## Exercícios Práticos
1. Renderize uma lista de produtos.
2. Crie uma condicional de login.
3. Adicione uma rota POST.
